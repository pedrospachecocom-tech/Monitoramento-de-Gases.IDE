Sistema IoT para Monitoramento de Segurança em Laboratórios Químicos
Desenvolvimento de sistema embarcado utilizando ESP32 para monitoramento de gases em laboratórios de química. 
O projeto realiza a detecção de NOx, CO e CH4 através dos sensores MQ135, MQ7 e MQ4, enviando dados em tempo real para a plataforma ThingSpeak via Wi-Fi. 
Implementação de lógica de alerta e perigo com sinalização visual por LEDs, além de filtragem de dados utilizando média móvel para maior estabilidade nas medições.
